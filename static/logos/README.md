# Loga KubiV

Tato složka slouží pro uložení log webu:

- `logo-flat.svg` - Vektorové jednobarevné logo (flat design) použité v horní navigační liště / hlavičce webu. Podporuje `fill="currentColor"`.
- `logo-3d.png` - Původní 3D logo v PNG formátu použité v úvodní sekci hlavní stránky (a případně jako reprezentativní avatar).
- `logo.svg` - Výchozí odkaz/kopie vektorového loga.
- `logo.png` - Výchozí odkaz/kopie rastrového loga.

> **Tip:** Své originální soubory log můžete kdykoliv nakopírovat do této složky a přepsat existující soubory se zachováním názvů `logo-flat.svg` a `logo-3d.png`. Pro interaktivní 3D model loga je určena složka `static/models/` (`logo.obj` nebo `logo.glb`). Web je okamžitě začne používat.
